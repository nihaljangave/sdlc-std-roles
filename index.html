Framework Automation CLI Commands

Use the master CLI helper ./scripts/sdlc-cli.sh to automate compliance in your terminal: 

# 1. Scaffold a new project (profiles: --standard, --enterprise, --ai, --all):
./scripts/sdlc-cli.sh scaffold ../my-new-product --enterprise

# 2. Audit compliance for a specific stage gate or all gates:
./scripts/sdlc-cli.sh audit 1 .
./scripts/sdlc-cli.sh audit all .

# 3. Generate client-ready and ops-ready release notes from Conventional Commits:
./scripts/sdlc-cli.sh release v0.9.0 HEAD v1.0.0

# 4. Generate 1-page weekly client delivery flash report:
./scripts/sdlc-cli.sh report "My Client MVP" 7

# 5. Package all formal deliverables into a signed client handover archive (.tar.gz):
./scripts/sdlc-cli.sh package . ./dist v1.0.0

# 6. Generate signed client milestone acceptance certificate stamped with Git SHA:
./scripts/sdlc-cli.sh signoff M4-Go-Live "Global Corp" "Core-Platform"

# 7. Execute synthetic post-verification (PVT) smoke test against deployment:
./scripts/sdlc-cli.sh smoke http://localhost:8000 15

# 8. Install local git hooks (blocks secret leaks & enforces Conventional Commits):
./scripts/sdlc-cli.sh hooks

# 9. Launch the searchable interactive documentation portal:
./scripts/sdlc-cli.sh portal

# 10. Execute Disaster Recovery PITR drill simulation and generate audit certificate:
./scripts/sdlc-cli.sh dr-drill "Core-Transactional-DB"

# 11. Generate CycloneDX v1.5 JSON SBOM manifest from dependencies:
./scripts/sdlc-cli.sh sbom . ./dist/sbom.cyclonedx.json

# 12. Run 30-second live SDLC simulation in ephemeral sandbox:
./scripts/sdlc-cli.sh demo
